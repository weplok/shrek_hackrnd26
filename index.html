Правила болота

  1. Стучать необязательно. Уходить обязательно.
  2. Свечи из ушной серы не трогать, они для ужина.
  3. Грязевые ванны строго по утрам.
  4. Ослам вход запрещён. Ну ладно, одному можно.
  5. Судить по внешности запрещено. Это главное правило.
  6. Сказочных героев не селить без согласия владельца.
